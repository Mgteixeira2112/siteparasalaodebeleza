# Sistema de Salão

Repositório do sistema de gerenciamento de salão de beleza.

## Backend

O backend usa o projeto Supabase compartilhado `mbsnmmhhvorkwmgzrnvi`, com isolamento lógico obrigatório por estruturas próprias do salão (`salon_*`).

## Regra de contribuição

Alterações funcionais devem ser feitas em branches pequenas e integradas por Pull Request após validação.
